## 子项目一览

| 目录 | 说明 |
|------|------|
| `route-service` | 路由 / 网关相关服务 |
| `web` | Web 端应用 |
| `admin` | 管理后台 |
| `flutter` | Flutter 客户端 |
| `chart` | 图表或可视化相关模块 |
| `server` | 服务端核心逻辑 |

各子目录保留原有工程结构；跨项目改动请在根目录统一提交，并遵循各子项目内的构建与运行说明。

## 仓库说明

- 本仓库为 **monorepo**：历史独立 Git 子目录已合并，全量代码由根仓库管理。
- 默认分支：`main`。
- 远程：`https://github.com/libai3699/IM.git`

## 快速开始

1. 克隆本仓库：`git clone https://github.com/libai3699/IM.git`
2. 进入对应子项目目录，按该项目的依赖安装与启动文档操作。
3. 生产部署请参考语雀 [生产环境部署](https://www.yuque.com/u1475064/mufu2a/iulf5xfqz1w9p4gi)。

## 许可证与贡献

各子项目可能沿用各自许可证；提交前请确认不引入敏感配置（密钥、内网地址等）。问题与改进建议可通过 Issue 或团队约定流程反馈。
